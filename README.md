# Trailmark Travel Planner

Trailmark is a responsive travel planner for organizing trip dates, itinerary stops, and preparation checklists.

## Stack

- Next.js App Router
- Supabase Auth and Postgres
- Vercel

## Local setup

1. Copy `.env.example` to `.env.local`.
2. Add the Supabase project URL and publishable key.
3. Install dependencies with `npm ci`.
4. Run `npm run dev`.

The deployed production project uses the matching `trailmark-travel-planner` name across GitHub, Supabase, and Vercel.
